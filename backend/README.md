# Back-End

Área responsável pela lógica e pelo processamento das informações do NutriFlow.

## Tecnologias
- Java
- Spring Boot
- Spring Data JPA
- Maven

## Responsabilidades
- Implementar as regras de negócio.
- Criar e disponibilizar APIs.
- Gerenciar autenticação e permissões.
- Processar os dados financeiros, da agenda e do marketing.
- Integrar a aplicação com o banco de dados e a API Gemini.
