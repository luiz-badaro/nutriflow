# Documentação

Área destinada aos documentos e materiais de apoio do NutriFlow.

## Organização

- `c4/contexto/`: diagrama de contexto.
- `c4/containers/`: diagrama de contêineres.
- `c4/componentes/`: diagramas de componentes.
- `c4/codigo/`: diagramas de código.
- `prototipos/`: protótipos e capturas das telas.
- `documentacao/`: documentos técnicos do projeto.
- `video/`: materiais relacionados à apresentação do projeto.
